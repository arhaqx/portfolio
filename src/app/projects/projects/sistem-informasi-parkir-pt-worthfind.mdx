## Overview

Proyek ini dibangun untuk **PT Worthfind Travel Goods Jepara** guna mengatasi pencatatan kendaraan masuk-keluar karyawan yang sebelumnya masih dilakukan secara manual. Sistem informasi internal berbasis web ini mendigitalkan seluruh pencatatan data dan rekapitulasi volume kendaraan.

## Fitur Utama

- **Pencatatan Real-time**: Input dan validasi data keluar-masuk kendaraan secara cepat oleh petugas parkir.
- **Monitoring Kapasitas Parkir**: Tampilan visual slot kapasitas parkir motor dan mobil secara live.
- **Laporan & Rekapitulasi Otomatis**: Ekspor data dan grafik statistik harian, mingguan, dan bulanan untuk audit internal.
- **Manajemen Karyawan & Hak Akses**: Pengaturan peran pengguna (Admin dan Operator).

## Teknologi yang Digunakan

- **Frontend & Backend**: Full Stack Web Application (PHP / Laravel / JavaScript)
- **Database**: MySQL / Relational Database
- **Interface**: Responsive UI dengan performa ringan untuk perangkat kantor
