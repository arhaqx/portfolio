## Overview

**HealSpace** adalah proyek akhir (Capstone Project) pada program **Dicoding Fullstack Web Developer Bootcamp**. Proyek ini bertujuan untuk menyediakan platform self-check kesehatan mental berbasis web yang mudah diakses, cepat, dan aman bagi pengguna umum.

## Peran & Tanggung Jawab

Sebagai **Full Stack Web Developer**, Arinal berkolaborasi secara intensif bersama tim pengembang untuk:
- Merancang arsitektur aplikasi end-to-end (front-end dan back-end).
- Mengembangkan RESTful API yang aman dan scalable untuk pemrosesan kuesioner dan data pengguna.
- Membangun antarmuka pengguna yang responsif, interaktif, dan mudah dipahami dengan React & Next.js.
- Mengoptimalkan performa queries dan response time server agar platform tetap stabil dalam beban akses tinggi.

## Fitur Utama

- **Kuesioner Self-Check Interaktif**: Alur pertanyaan dinamis dengan kalkulasi skor otomatis untuk indikasi awal kesehatan mental.
- **Hasil & Rekomendasi Terstruktur**: Tampilan hasil self-check yang informatif disertai saran tindak lanjut yang dapat diunduh atau disimpan.
- **Manajemen Pengguna & Privasi**: Autentikasi aman dan proteksi data sensitif pengguna.
- **Dashboard & Analitik Ringkas**: Tampilan monitoring riwayat self-check untuk evaluasi berkala.

## Teknologi yang Digunakan

- **Frontend**: React, Next.js, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express / Hapi, RESTful API
- **Database & Deployment**: Cloud Database, CI/CD Pipeline
